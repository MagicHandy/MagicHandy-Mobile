# Port deviations

**Startup Stop evidence.** At `1b80d72e`, `internal/motion/startup.go` and its `stopTransportForStartup` helper treat the absence of a transport error as success even when the command result reports failure. Mobile requires an acknowledged halt before reading calibration or sending a positioning command. `StartupReconciliationTest` exercises an unsuccessful Stop and a Stop during positioning. Desktop should also check the result.
