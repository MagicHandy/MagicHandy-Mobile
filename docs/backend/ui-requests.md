The two additional `StopSource` entries are `ModelReply` and `CheckInTimeout`. Check any future exhaustive consumer. The current UI builds and passes its boundary tests.

**Form messages by intent**

| Form | What the UI can say |
|---|---|
| Handy key or Autoblow token | Check the key or token and name, complete onboarding, or open the existing device for a duplicate. An accepted save stores the credential. |
| Intiface device | Correct the address, reach the bridge, select a unique device and feature again, or open the existing saved device. `NeedsSetup` after reconnect calls for re-selection. |
| LAN server | Check the private address, selected model and server availability. Distinguish provider refusal from network loss. A newer check can supersede a pending one. |
| OpenRouter | Check the key or model name. A duplicate already has a saved row. |
| Rename device | Retain the proposed name if it is empty, invalid or taken. A missing device may already have been removed. |
| Remove device | Wait for a connection attempt, stop the active run or finish the local Stop check before trying again. |
| Remove connection | Wait for the active role to be released, or refresh the list if it was already removed. |

Handle `Busy`, `Unsupported` and `StorageUnavailable` for every form. The motor-test duration is confirmed at 1.5 seconds. Settings in the bottom row is confirmed. [Detailed form contract](contract-changes.md)
