# MagicHandy Mobile v0.1.7

## Changelog

- The Handy now connects over **Bluetooth on this phone**. In 0.1.6, every Bluetooth attempt ended in **Couldn't verify**. The Stop receipt now confirms Stop for a Handy connected over Bluetooth.
- A Handy saved during a failed attempt in 0.1.6 is still listed in **Devices**. Tap **Connect** there, or remove it and add it again.
- An Original Handy connected over Bluetooth now receives the same point density as over Handy Cloud. This density gave smoother motion on that model in earlier testing over Cloud.
- When a nearby device can't be verified, tap **Retry** in its row instead of leaving the page.
- **Handy Cloud** is labelled **Recommended** when you add The Handy.
- The owner tested the Bluetooth connection fix with an Original Handy using a test build. The motion change hasn't been tested over Bluetooth yet.
- Install `MagicHandy-0.1.7.apk` over 0.1.6 to keep your chats, settings and devices. The matching checksum is in `SHA256SUMS`.
