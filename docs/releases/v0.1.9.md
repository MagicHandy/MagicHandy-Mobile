# MagicHandy Mobile v0.1.9

## Changelog

- In **Models**, add or edit an OpenRouter connection, search the model list, compare estimated prices, and choose how much reasoning a model uses. Leave the key field empty when editing to keep your saved key.
- Autopilot tells you when a sign-in, API key, or billing issue needs attention. It holds planning while you fix the issue and retries temporary outages automatically. The current motion can continue while planning is on hold. Tap **Stop** to end motion.
- When you change the pace in Chat, Autopilot gives it time to play. Chat and Live show the current and next pace while a change is waiting. Replies also show when a stroke pattern changes at the same pace.
- Scroll back to read older messages. Drafts stay with their own chats. In long conversations, the model can refer back to a short excerpt from the opening messages.
- On a single Original Handy connected by Bluetooth, slow strokes now use gentler commands near each change of direction. On Handy Cloud, if the slider stops short while resuming and the device confirms it has stopped, the run stays paused. Check that the slider can move freely, then tap **Resume** to try again.
- Fixed a voice-input issue where words recorded before **Stop** could reach Chat afterward. Pausing and restarting speech-model downloads is more reliable, and downloads started in Settings keep the microphone off.
- Install `MagicHandy-0.1.9.apk` over the public 0.1.8 app to keep your chats, settings, and devices. The matching checksum is in `SHA256SUMS`.
