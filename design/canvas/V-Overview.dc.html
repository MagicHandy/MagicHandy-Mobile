MagicHandy Mobile
v1 direction · Graphite Mobile

A conversation you run from a phone in one hand. Connect the devices you want, then start motion yourself or let Autopilot take over. One line says what the app is commanding; tap it for Live. Settings that can wait sit in one compact sheet. Stop is always the last row.

Not in v1: pattern library, video and funscripts, voice, Labs, desktop administration, model installs. On-device models come after v1.

Kept on purpose

  • Every desktop device family, including several Handys
  • Autopilot with the screen off
  • Layered, Simple and Off at every capability level
  • Edge, which you asked for on the phone remote
  • Style, memory, five languages
  • Notification, lock screen and tile Stop

Rules nothing may break

  • One engine writes to devices; chat and Autopilot only ask
  • Stop fences late commands and reaches every device
  • Outcomes are never claimed without an acknowledgement
  • Connecting never starts motion; reconnecting never rejoins a run
  • The run journal is written before the first motion command
